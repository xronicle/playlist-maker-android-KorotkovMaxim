Задача 1. Вёрстка экрана поиска

1. Реализована вёрстка `SearchScreen` по макету Figma
2. Реализована логика сброса поискового запроса
3. Для поисковой строки использована compose-функция `OutlineTextField`
4. Текст-подсказка корректно отображается
5. Размещена иконка "х" в конце поля ввода
6. Размещена иконка "лупа" в начале поля ввода

Задача 2. Вёрстка экрана настроек

1. Готова вёрстка `SettingsScreen` по макету Figma
2. Реализованы кнопки "Поделиться приложением", "Написать разработчикам", "Пользовательское соглашение"
3. При нажатии на кнопку "Поделиться приложением" появляется диалог для шеринга сообщения
4. При нажатии на кнопку "Написать разработчикам" открывается почтовый клиент с заполненными полями
5. При нажатии на кнопку "Пользовательское соглашение" открывается браузер с ссылкой на оферту на оказание образовательных услуг Яндекс Практикума
6. Все строки и иконки вынесены в ресурсы, цвета и типография вынесены в отдельную тему (еще в 3 спринте)

Задача 3. Переходы между экранами

1. Создать enum-класс с перечислением имеющихся экранов
2. Создать метод `PlaylistHost`, который вызывает `NavHost`
3. Реализовать методы переходов на другие экраны, используя `navController` и ранее созданный enum-класс
