# Проект на Jetpack Compose от Яндекс.Практикум
Приложение для поиска музыкальных треков, создания плейлистов и работы с избранным. Проект разработан в рамках обучения в Яндекс.Практикуме с использованием Jetpack Compose.

## Конфигурация проекта
- Android Studio 2025.1.4
- Kotlin: 2.0.21
- jdk = 21
- minSdk = 29
- targetSdk = 36

## Шаги запуска
1. Открыть проект в Android Studio
2. Дождаться импорта всех зависимостей gradle
3. Нажать кнопку "Run"
